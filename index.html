Controller API reference

Global within student code · refreshed each step

Write function controller() and any number of helper functions. Use state, params, and memory directly in any function. Do not declare these three names at the top level. The simulator calls controller() automatically; the previous controller(state, params, memory) signature also works.

state read only · current particle and target

state.x, state.y
Particle position (m)
state.vx, state.vy
Particle velocity (m/s)
state.t
Simulation time (s)
state.target.x, .y
Target position (m)
state.target.vx, .vy
Target velocity (m/s)
state.target.ax, .ay
Target acceleration (m/s²)

params read only · physics and sampling

params.m
Mass (kg)
params.b
Viscous damping (N·s/m)
params.fmax
Force limit per axis (N)
params.dt
Selected sample period = 0.020 s (50 Hz)

memory read / write · your stored variables

Starts as {}, survives between controller calls, and is cleared by Reset or Apply & reset. Each test starts with empty memory. Only your JavaScript updates memory: the simulator stores it but never computes controller history or observer states for you.

Example: accumulate a value using the sample time
memory.sum = (memory.sum || 0)
  + (state.target.x - state.x) * params.dt;
Helper function reading globals (no arguments)
function errorX() {
  return state.target.x - state.x;
}

Your function must return { fx, fy } in newtons. The simulator clips each force to [-params.fmax, +params.fmax] and then advances the plant.

Ts = 0.020 s (50 Hz) · 30 s max

How we discretize the plant

The controller runs once per selected sampling period Δt = params.dt = 0.020 s. Its force stays constant during that step. For the x axis:

ax      = (fx - b * vx + disturbanceX) / m;
vxNext  = vx + ax * dt;
xNext   = x + vxNext * dt;

The y axis is updated identically (fy, vy, y). Then tNext = t + dt.

This is semi-implicit Euler (also called symplectic Euler): update velocity first, then use the new velocity for position. It approximates the continuous plant m·ẍ + b·ẋ = fx + disturbanceX, not an exact zero-order-hold discretization.
